One line, under 200 characters: the funniest sick-day excuse that still gets you the day off.

Run `node main.ts` — it writes the excuse to `/output/entry.txt` (84 characters, with a read-back self-check).

> Out today — I threw my back out reaching for my phone charger. The charger survived.
